## 🚀 БЫСТРЫЙ СТАРТ

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Запустить фронтенд

```bash
# Вариант 1: Через скрипт
python scripts/run_frontend.py

# Вариант 2: Напрямую
cd frontend
python app.py

# Вариант 3: Через uvicorn
uvicorn frontend.app:app --reload --host 0.0.0.0 --port 8000
```

### 3. Открыть в браузере

```
http://localhost:8000
```

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Структура API

**GET `/api/orders`**
- Параметры: `page`, `per_page`, `status`, `search`
- Возвращает: список заказов с информацией о синхронизации

**GET `/api/orders/{order_id}`**
- Возвращает: полные детали заказа + статус синхронизации

**POST `/api/orders/{order_id}/sync`**
- Синхронизирует заказ в LILU
- Возвращает: результат синхронизации

**GET `/api/sync/status`**
- Возвращает: статистику синхронизации

### Интеграция компонентов

```python
# При старте приложения
wc_connector = WooCommerceConnector()
lilu_connector = LILUConnector()
sync_service = SyncService(
    wc_connector=wc_connector,
    lilu_connector=lilu_connector,
    default_tag="api woo"
)

# При синхронизации заказа
order = Order.from_dict(order_data)
result = sync_service.sync_order(order)
```
