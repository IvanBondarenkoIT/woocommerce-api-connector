## 🧪 Как запустить тесты

### Все тесты синхронизации

```bash
# Все тесты синхронизации
python -m pytest tests/test_phone_normalizer.py tests/test_sync_tracker.py tests/test_order_processor.py tests/test_sync_service.py -v

# С покрытием
python -m pytest tests/test_phone_normalizer.py tests/test_sync_tracker.py tests/test_order_processor.py tests/test_sync_service.py -v --cov=woocommerce_connector.services --cov=woocommerce_connector.utils.phone_normalizer
```

### Отдельные тесты

```bash
# Только нормализация телефонов
python -m pytest tests/test_phone_normalizer.py -v

# Только трекер
python -m pytest tests/test_sync_tracker.py -v

# Только обработчик заказов
python -m pytest tests/test_order_processor.py -v

# Только сервис синхронизации
python -m pytest tests/test_sync_service.py -v
```
