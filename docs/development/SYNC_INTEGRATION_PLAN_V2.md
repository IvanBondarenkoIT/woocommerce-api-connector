# 🔄 План интеграции синхронизации WooCommerce → LILU (Версия 2.0)

## 📋 Цель проекта

Автоматически синхронизировать заказы из WooCommerce в CRM LILU:
1. Отлавливать новые заказы из WooCommerce
2. Извлекать информацию о клиенте (телефон, имя, email)
3. Ищет клиента в LILU по номеру телефона
4. Если клиент не найден - создавать нового с тегом "api woo"
5. Возможность добавлять дополнительные теги в зависимости от целей и акций

# POST /orders/{id}/sync - синхронизировать заказ в LILU

#### 1.4 Страница списка заказов

**Функционал:**
- Таблица с заказами (ID, дата, клиент, сумма, статус)
- Фильтры: по статусу, по дате
- Поиск по ID заказа или имени клиента
- Пагинация
- Кнопка "Синхронизировать" для каждого заказа
- Индикатор статуса синхронизации (✅ синхронизирован, ⏳ не синхронизирован)

**Данные в таблице:**
- ID заказа
- Дата создания
- Имя клиента (из billing)
- Телефон клиента
- Email клиента
- Сумма заказа
- Статус заказа
- Статус синхронизации (синхронизирован/не синхронизирован)
- LILU Client ID (если синхронизирован)

#### 1.5 Страница деталей заказа

**Функционал:**
- Полная информация о заказе
- Информация о клиенте (телефон, имя, email)
- Список товаров в заказе
- Кнопка "Синхронизировать в LILU"
- Результат синхронизации (успех/ошибка)
- Информация о клиенте в LILU (если синхронизирован)

#### 1.6 Кнопка "Синхронизировать заказ"

**Функционал:**
- При нажатии вызывает API endpoint `/orders/{id}/sync`
- Показывает процесс синхронизации (loading)
- Отображает результат:
  - ✅ Клиент создан в LILU (ID: ...)
  - ✅ Клиент обновлен в LILU (ID: ...)
  - ⚠️ Заказ пропущен (нет телефона)
  - ❌ Ошибка синхронизации: ...
- Обновляет статус заказа в интерфейсе

#### 1.7 Статус синхронизации

**Визуальные индикаторы:**
- 🟢 Синхронизирован - заказ успешно синхронизирован
- 🟡 В процессе - синхронизация выполняется
- 🔴 Ошибка - ошибка при синхронизации
- ⚪ Не синхронизирован - заказ еще не синхронизирован

#### 2.3 Интеграция с существующими компонентами

```python
from woocommerce_connector.connector import WooCommerceConnector
from lilu_connector.connector import LILUConnector
from woocommerce_connector.services import SyncService

# Инициализация (один раз при старте)
wc_connector = WooCommerceConnector()
lilu_connector = LILUConnector()
sync_service = SyncService(
    wc_connector=wc_connector,
    lilu_connector=lilu_connector,
    default_tag="api woo"
)

# В endpoint синхронизации
@app.post("/api/orders/{order_id}/sync")
async def sync_order(order_id: int):
    order_data = wc_connector.get_order_by_id(order_id)
    order = Order.from_dict(order_data)
    result = sync_service.sync_order(order)
    return result
```

### ЭТАП 5: АВТОМАТИЗАЦИЯ (Приоритет: 🟡 ВАЖНО - после тестирования)

#### 5.1 Автоматическая синхронизация по расписанию

**Варианты реализации:**
- **APScheduler** - планировщик задач для Python
- **Celery** - распределенная очередь задач (для production)
- **Cron** - системный планировщик (простой вариант)

**Рекомендация:** APScheduler для начала (просто, встроен в приложение)

#### 5.2 Настройка расписания

**Варианты:**
- Каждые N минут (например, каждые 5 минут)
- По расписанию (например, каждый час в 00 минут)
- При старте приложения + по расписанию

**Конфигурация:**
```python
# В .env
SYNC_AUTO_ENABLED=true
SYNC_INTERVAL_MINUTES=5
SYNC_ON_STARTUP=true
```

#### 5.3 Фоновая задача синхронизации

```python
from apscheduler.schedulers.background import BackgroundScheduler

scheduler = BackgroundScheduler()

@scheduler.scheduled_job('interval', minutes=5)
def auto_sync_new_orders():
    """Автоматическая синхронизация новых заказов каждые 5 минут."""
    results = sync_service.sync_new_orders()
    logger.info(f"Auto-sync completed: {len(results)} orders processed")
```

#### 5.4 Управление автоматической синхронизацией

**API endpoints:**
- `POST /api/sync/auto/start` - запустить автоматическую синхронизацию
- `POST /api/sync/auto/stop` - остановить
- `GET /api/sync/auto/status` - статус автоматической синхронизации

**В интерфейсе:**
- Переключатель "Автоматическая синхронизация"
- Настройки интервала
- Лог последних синхронизаций

### Поток данных

```

   ↓

   ↓
3. Backend → WooCommerceConnector.get_all_orders()
   ↓
4. Frontend отображает заказы в таблице
   ↓
5. Пользователь нажимает "Синхронизировать"
   ↓
6. Frontend → POST /api/orders/{id}/sync
   ↓
7. Backend → SyncService.sync_order()
   ↓
8. SyncService:
   - Извлекает данные клиента
   - Ищет в LILU по телефону
   - Создает/обновляет клиента
   ↓
9. Backend → Frontend: результат синхронизации
   ↓
10. Frontend обновляет статус заказа
```
