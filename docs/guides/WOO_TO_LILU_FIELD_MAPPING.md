# Сопоставление полей WooCommerce → LILU

Справочник по маппингу данных при импорте клиентов из WooCommerce в LILU CRM через синхронизацию.

## Обязательные поля

| WooCommerce (заказ/billing) | LILU (people) | Примечание |
|-----------------------------|---------------|------------|
| `billing.first_name` + `billing.last_name` | `name` | Имя клиента. Если пусто — используется телефон |
| `billing.phone` | `phone` | Нормализуется через PhoneNormalizer. **Без телефона заказ не импортируется** |
| `billing.email` | `email` | Если пусто — `woo-order-{id}@import.placeholder` |

## Теги

| Правило | LILU `tags` |
|---------|-------------|
| Всегда | `api woo` — для всех клиентов, импортированных через sync |
| Позже | Теги по группам товаров (пока не реализовано) |

## Метаданные (metadata)

В `metadata` нового клиента сохраняется информация о заказе:

| Ключ | Значение |
|------|----------|
| `woo_order_id` | ID заказа в WooCommerce |
| `woo_order_date` | Дата заказа |
| `woo_order_total` | Сумма и валюта (напр. `99.99 GEL`) |
| `woo_order_products` | Строка: перечень товаров (напр. `Товар 1 x2, Товар 2 x1`) |
| `woo_order_summary` | Полная сводка заказа — готовый текст для стартового сообщения в переписку |
| `woo_imported_at` | Время импорта (ISO 8601) |

## Стартовое сообщение

`woo_order_summary` можно использовать как начало переписки с клиентом. Пример:

```
Заказ WooCommerce #123
Дата: 2025-01-27T10:00:00
Сумма: 99.99 GEL
Статус: completed
Товары: Товар 1 x2, Товар 2 x1
Телефон клиента: +7 999 123-45-67
```

Для автоматической отправки стартового сообщения потребуется интеграция с API отправки сообщений LILU (отдельная доработка).

## Сопоставление источников

- **Имя**: `order.billing.first_name` + `order.billing.last_name` или `order.customer_name`
- **Телефон**: `order.billing.phone` (обязательно, иначе заказ пропускается)
- **Email**: `order.billing.email`
- **Товары**: `order.line_items[]` → `name`, `quantity`
- **Сумма**: `order.total`, `order.currency`
- **Дата**: `order.date_created`
- **Статус**: `order.status`

## Обновление существующих клиентов

При найденном клиенте по телефону обновляются только **теги**. Метаданные не перезаписываются, чтобы сохранить историю по первому заказу.
